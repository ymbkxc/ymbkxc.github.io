# 二、逐个会议说明

## 1. NeurIPS

### 全称

**Conference on Neural Information Processing Systems**

以前常写作 NIPS，后来更名为 NeurIPS。

### 主要方向

NeurIPS 是当前机器学习领域最重要的综合性会议之一，覆盖范围很广：

- Deep Learning
- Foundation Models
- LLM
- Multimodal Learning
- Reinforcement Learning
- Generative Models
- Diffusion Models
- Optimization
- Probabilistic Machine Learning
- Representation Learning
- AI Safety / Alignment
- Machine Learning Theory
- Computational Neuroscience
- Robotics / Embodied Learning

### 组织方

核心常设组织为：

**Neural Information Processing Systems Foundation**

不是由 Google、OpenAI、Meta 等公司直接主办。

每届大会的 Program Chairs、General Chairs、Area Chairs 等来自全球高校、研究机构和企业实验室。

### 国家 / 总部

- 主要法律与组织体系：美国
- 公开联系地址：美国加州圣迭戈
- 实际组织方式：基金会 + 全球学术委员会 + 专业会务团队

### 主要收入与运营方式

主要来源包括：

- 参会注册费
- 企业 Sponsorship
- Expo / 展位
- 招聘与品牌展示
- 虚拟参会相关费用

企业赞助通常换取：

- 展位
- Logo 展示
- 招聘曝光
- Expo Talk
- Complimentary Registration

学术录用和赞助体系原则上分离。

---

## 2. ICML

### 全称

**International Conference on Machine Learning**

### 主要方向

ICML 更聚焦“机器学习本身”：

- Machine Learning Theory
- Optimization
- Deep Learning
- Reinforcement Learning
- Representation Learning
- Generative Models
- Probabilistic Models
- Generalization
- Causal Learning
- Robustness
- Federated Learning
- Foundation Models

相较 NeurIPS，ICML 通常更加集中在 ML 方法论和理论。

### 组织方

核心治理与法律体系通常归于：

**International Machine Learning Society**

以及 ICML 的 Steering / Organizing Committee。

### 国家 / 总部

- 美国注册
- 属于美国税务体系下的非营利学术组织
- 不像 ACM 那样强调一个固定大型总部
- 更接近“美国注册法人 + 全球学术委员会”的模式

### 主要收入与运营方式

主要来源：

- 注册费
- 企业赞助
- Expo
- 招聘与展位
- 企业合作

部分赞助资金会用于：

- Graduate Student Grants
- Travel Support
- Inclusion Programs

---

## 3. ICLR

### 全称

**International Conference on Learning Representations**

### 主要方向

ICLR 是深度学习和表示学习时代成长起来的重要会议。

重点包括：

- Deep Learning
- Representation Learning
- LLM
- Transformer
- Generative AI
- Diffusion
- Multimodal Learning
- Self-Supervised Learning
- Reinforcement Learning
- Neural Architecture
- Optimization
- Foundation Models
- Mechanistic Understanding

如果研究 LLM、VLM、VLA、Diffusion、Agent，ICLR 是非常重要的会议。

### 组织方

主要是：

**ICLR 学术治理体系 / Steering Committee / Organizing Committee**

ICLR 很早就大规模采用 OpenReview。

### 国家 / 总部

- 国际化治理特征明显
- 不像 ACM、AAAI 那样强调一个固定总部
- 依靠全球学术委员会与年度组织委员会运作

### 主要收入与运营方式

主要来源：

- 注册费
- Sponsorship
- Exhibitor
- 企业招聘
- 学术与青年研究人员资助项目

---

## 4. AAAI

### 全称

会议名称：

**AAAI Conference on Artificial Intelligence**

背后的学术组织：

**Association for the Advancement of Artificial Intelligence**

### 主要方向

AAAI 是综合人工智能会议，不只关注机器学习：

- Machine Learning
- NLP
- Computer Vision
- Knowledge Representation
- Reasoning
- Planning
- Search
- Constraint Satisfaction
- Agents
- Robotics
- Multi-Agent Systems
- AI Ethics
- AI Applications

### 组织方

**Association for the Advancement of Artificial Intelligence**

是长期运营的非营利学术协会。

### 国家 / 总部

- 美国
- 主要办公与治理体系位于美国加州
- 历史上 Menlo Park、Palo Alto 一带与其联系密切

### 主要收入与运营方式

来源包括：

- Conference Registration
- Membership
- Sponsorship
- Publication
- Donations / Grants
- 学术活动收入

---

## 5. IJCAI

### 全称

**International Joint Conference on Artificial Intelligence**

### 主要方向

属于综合人工智能顶级会议体系：

- AI Foundations
- Machine Learning
- Reasoning
- Knowledge Representation
- Planning
- Agents
- Robotics
- NLP
- Computer Vision
- Responsible AI

### 组织方

**IJCAI Organization**

### 国家 / 总部

- 美国注册
- 加州法律体系下的非营利组织
- 日常更偏向 Secretariat / 委员会治理，不突出实体总部

### 主要收入与运营方式

主要包括：

- 注册费
- Sponsorship
- 学术出版与会议相关收入
- Workshop / Tutorial 等活动费用

IJCAI 的 proceedings 通常可在线公开访问。

---

## 6. AISTATS

### 全称

**International Conference on Artificial Intelligence and Statistics**

### 主要方向

AISTATS 的定位非常明确：

**Artificial Intelligence + Statistics**

主要包括：

- Statistical Machine Learning
- Bayesian Methods
- Causal Inference
- Optimization
- Probabilistic Modeling
- Learning Theory
- Graphical Models
- Uncertainty
- High-Dimensional Statistics

相较 NeurIPS / ICML，AISTATS 通常更加偏统计学与数学方法。

### 组织方

主要由：

- Steering Committee
- Organizing Committee
- Program Committee

共同组织。

### 国家 / 总部

- 国际化学术共同体
- 固定总部概念弱
- 每年由不同国家和机构的学者共同组织

### 论文出版

Accepted Papers 通常进入：

**Proceedings of Machine Learning Research, PMLR**

论文通常可以免费公开阅读。

### 主要收入与运营方式

- 注册费
- Sponsorship
- 学术会议相关费用

整体商业化程度通常低于 NeurIPS、ICML。

---

## 7. UAI

### 全称

**Conference on Uncertainty in Artificial Intelligence**

### 主要方向

UAI 的传统特色非常鲜明：

- Bayesian Networks
- Probabilistic Graphical Models
- Bayesian Inference
- Causal Inference
- Decision Theory
- Uncertainty Quantification
- Probabilistic Machine Learning
- Sequential Decision Making

传统强项：

**概率图模型 + 因果推断 + 不确定性推理**

### 组织方

**Association for Uncertainty in Artificial Intelligence**

### 国家 / 总部

- 北美学术传统很强
- 历史上与加拿大 University of British Columbia 等机构联系较深
- 当前更强调全球委员会治理，不突出固定大型总部

### 主要收入与运营方式

主要依靠：

- 注册费
- Sponsorship
- 学术会议相关收入

---

## 8. AAMAS

### 全称

**International Conference on Autonomous Agents and Multiagent Systems**

### 主要方向

AAMAS 是 Agent 和 Multi-Agent 领域最重要的会议之一。

主要方向：

- Autonomous Agents
- Multi-Agent Systems
- Agent Architectures
- Agent Communication
- Coordination
- Cooperation
- Competition
- Game Theory
- Mechanism Design
- Multi-Agent Reinforcement Learning
- Social Choice
- Agent Planning
- Human-Agent Interaction

需要注意：

AAMAS 的 Agent 概念远早于当前流行的 LLM Agent。

### 组织方

**IFAAMAS**

全称：

**International Foundation for Autonomous Agents and Multiagent Systems**

### 国家 / 总部

- 美国
- 法律与注册体系位于美国南卡罗来纳州
- 属于非营利学术组织

### 历史

AAMAS 在 2002 年由多个相关会议整合而来，包括：

- AGENTS
- ICMAS
- ATAL

### 主要收入与运营方式

- 注册费
- Sponsorship
- Workshop / Tutorial
- 学术社区运营收入

---

## 9. KDD

### 全称

**ACM SIGKDD Conference on Knowledge Discovery and Data Mining**

### 主要方向

KDD 偏向：

**大规模真实数据 + 工业应用 + 数据挖掘**

典型方向：

- Data Mining
- Recommender Systems
- Graph Mining
- Graph Neural Networks
- Fraud Detection
- Search / Ads
- User Modeling
- Time Series
- Anomaly Detection
- Applied ML
- Industrial AI
- Large-Scale ML

互联网公司通常非常重视 KDD。

### 组织方

**ACM SIGKDD**

即：

**ACM Special Interest Group on Knowledge Discovery and Data Mining**

其上层组织是：

**ACM — Association for Computing Machinery**

### 国家 / 总部

- 美国
- ACM 总部位于纽约

### 主要收入与运营方式

- 注册费
- 企业赞助
- Expo / 展位
- 招聘活动
- ACM 会员体系
- ACM Digital Library 相关出版体系

# 四、这些会议是谁“发起”的

不能简单理解成“某家公司主办”。

更准确的分类如下。

## 1. 独立非营利基金会 / 学术组织

包括：

- NeurIPS Foundation → NeurIPS
- International Machine Learning Society → ICML
- AAAI → AAAI Conference
- IJCAI Organization → IJCAI
- IFAAMAS → AAMAS
- AUAI → UAI

这些组织的核心目标是：

- 维护学术社区
- 组织会议
- 管理学术评审
- 支持学生和青年研究者
- 维护长期学术品牌

---

## 2. ACM 体系

主要包括：

- KDD
- WWW
- SIGIR
- CIKM

基本结构可以理解为：

```text
ACM
├── SIGKDD
│   └── KDD
├── SIGIR
│   └── SIGIR Conference
├── SIGWEB
│   └── The Web Conference
└── 多个相关 SIG
    └── CIKM
```

ACM 是全球最大的计算机学术组织之一，总部在美国纽约。

---

## 3. 国际学术共同体治理型

包括：

- ICLR
- AISTATS

这类会议通常：

- 没有很强的实体总部概念
- 依赖 Steering Committee
- 依赖 General Chairs / Program Chairs
- 每年由全球不同机构的研究者共同组织

# 六、为什么很多会议“是国际会议”，但组织体系却在美国

原因主要有：

1. 现代计算机科学学术体系很大程度上在美国高校和学会体系中制度化。
2. ACM、AAAI、NeurIPS Foundation、ICML 等长期采用美国非营利法人框架。
3. 美国非营利组织、税务、基金会和学术协会制度成熟。
4. 很多会议虽然法律实体在美国，但：
   - 主席来自全球
   - 作者来自全球
   - 会议地点全球轮换
   - Program Committee 全球化
   - Reviewer 全球化

因此：

**法律注册地不等于学术影响力只属于某个国家。**

# 七、“总部”和“当年举办地”必须区分

例如：

- ACM 总部在纽约
- SIGIR 可以在欧洲开
- KDD 可以在亚洲开
- NeurIPS 可以在不同国家和城市举办
- ICML 每年也会轮换城市

因此需要区分四个概念：

### 1. 法律实体注册地

决定：

- 税务
- 财务
- 法律责任

### 2. 常设组织总部 / 秘书处

负责：

- 长期管理
- 财务
- 品牌
- 合同

### 3. 当届 Organizing Committee

负责：

- Program
- Review
- Workshop
- Tutorial
- Sponsor
- Registration

### 4. 当届 Conference Venue

只是：

- 这一届实际在哪里开

不能因为某一届会议在欧洲，就认为该会议“总部在欧洲”。

# 十、简要结论

如果从“学术定位 + 组织体系 + 商业模式”三个维度看，这 12 个会议可以概括为：

- **NeurIPS / ICML / ICLR**：现代机器学习与基础模型核心会议
- **AAAI / IJCAI**：综合人工智能
- **AISTATS / UAI**：统计、概率、因果与不确定性
- **AAMAS**：Agent 与 Multi-Agent
- **KDD / WWW**：数据挖掘、Web、工业应用
- **SIGIR / CIKM**：搜索、信息检索、知识与数据管理

它们绝大多数不是商业公司会议，而是由：

- 非营利基金会
- 学术协会
- ACM Special Interest Group
- 国际学术共同体

长期运营。

收入主要来自：

- 注册费
- 企业赞助
- 展位 / Expo
- 会员费
- 出版与数字图书馆
- Workshop / Tutorial

这些收入通常用于：

- 会务成本
- 场地
- 技术平台
- 学生差旅
- 学术资助
- 社区运营
- 下一届会议
- 长期学术组织维护
